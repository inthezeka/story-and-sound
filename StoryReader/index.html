소설 원고 및 음악 관리

현재 편집 기준: 게시된 최신 원고

관리자 화면은 기본적으로 독자가 읽는 최신 GitHub 원고를 표시합니다. 개인 초안을 불러오는 경우에만 내용이 다를 수 있습니다. 편집 내용은 브라우저에 먼저 저장되며 자동 게시되지 않습니다.

챕터별 소설 원고를 직접 입력하거나 TXT로 가져오고, 음악과 배경을 설정하세요. 모든 업로드 파일은 먼저 현재 브라우저에 보관됩니다.

UTF-8 텍스트 파일을 권장합니다. 기존 원고를 교체합니다.

콘텐츠 배포 및 백업

이 페이지의 관리자 모드는 로컬 편집기입니다. 로그인이나 관리자 권한 인증을 제공하지 않으며, 다른 방문자가 자신의 브라우저에서 편집하더라도 공개 사이트는 변경되지 않습니다. 외부 공개는 content.json을 다운로드해서 GitHub에 직접 업로드해야 완료됩니다.

웹사이트에 콘텐츠 게시

STEP 01

원고와 장면 설정을 저장합니다. 아래 버튼을 누르면 MP3와 이미지가 내부에 포함된 content.json 파일이 생성됩니다.

STEP 02

GitHub 저장소의 index.html과 같은 폴더에 content.json 파일을 업로드하거나 기존 파일을 교체합니다.

STEP 03

GitHub Pages 배포가 끝나면 다른 기기에서 사이트를 새로고침하여 확인합니다. 음원이 많으면 JSON 파일이 매우 커질 수 있습니다.

다른 브라우저에서 원고 이어 편집하기

내보낸 content.json을 다른 기기에서 가져올 수 있습니다. 원고·장면별 음악·이미지가 함께 복원됩니다. 가져오기는 이 브라우저에 저장된 초안을 교체합니다.
